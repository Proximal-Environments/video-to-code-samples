# Designing Animations

This page serves as a landing/overview page for the "Designing Videos" section of the Revideo documentation.

- Revideo was created as a fork of Motion Canvas, and the APIs for designing animations are largely similar.
- For comprehensive guidance on building animations, consult the Motion Canvas Guide section.
- Revideo-specific modifications (such as Rive animation support) and use-case-relevant information are documented in separate sections.
- The Code Snippets section offers implementation examples for common animation scenarios, including streaming text effects and moving/manipulating objects.
